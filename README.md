# 🎉 EventEase – Smart Celebration Planner

EventEase is a modern and user-friendly event planning website designed to make organizing celebrations easier and more efficient. It helps users plan events, manage budgets, explore themes, organize guests, and track important tasks in one place.

## ✨ Features

- **Event Creation:** Plan weddings, birthdays, college events, parties, and more.
- **Budget Management:** Track and manage event expenses.
- **Theme Selection:** Explore creative themes for different celebrations.
- **Guest Management:** Organize guest lists and track RSVP status.
- **Task Checklist:** Manage event tasks and monitor completion.
- **Event Dashboard:** View event details and planning progress.
- **Responsive Design:** Accessible across desktop, tablet, and mobile devices.

## 🎯 Problem Statement

Planning celebrations involves managing multiple activities, expenses, guests, and deadlines. EventEase aims to simplify this process through a centralized event planning platform.

## 💡 Our Solution

EventEase provides an organized digital platform that brings essential event planning activities together, saving time and improving planning efficiency.
